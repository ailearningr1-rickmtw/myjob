# AERO-NEXUS 多功能科技清新工作中樞

本專案為結合「科技感」與「清新自然視覺」的模組化個人工作中樞平台，採前後端分離目錄結構設計，並內建 GitHub Actions 自動部署流程，可直接發布至 GitHub Pages。

## 專案目錄結構

- `public/`：存放所有網頁前端靜態資源（包含 `index.html`、`404.html`、`css/style.css`、`js/app.js`）。所有內部資源連結均採用相對路徑，完全相容 GitHub Pages 子路徑。
- `src/`：存放 Python 3.11+ 自動化建置與驗證工具（`build.py`）。
- `.github/workflows/deploy.yml`：GitHub Actions 自動化部署設定，當推送至 `main` 分支時自動將 `public/` 部署至 GitHub Pages。

## 五大預留核心主題

1. **主題一：任務與專案中樞 (MOD-01)** — 整合日常工作待辦、專案進度追蹤與會議行動項目。
2. **主題二：自動化與效率工具箱 (MOD-02)** — 放置格式轉換器、範本生成與 Python 自動化腳本輸出介面。
3. **主題三：數據觀測與視覺化儀表板 (MOD-03)** — 呈現關鍵業務指標、工時統計與視覺化圖表。
4. **主題四：知識庫與技術文件中心 (MOD-04)** — 集中管理標準作業流程（SOP）、技術筆記與常見問題索引。
5. **主題五：跨域資源與外部連結導航 (MOD-05)** — 彙整常用內部系統入口、AI 提示詞庫與設計資源跳板。

## 本地端預覽與驗證方式

於專案根目錄執行以下指令，即可自動同步 `404.html`、驗證無 Inline CSS 並啟動本地端預覽伺服器：

```bash
python src/build.py --serve --port 8000
```

接著於瀏覽器開啟 `http://localhost:8000` 即可檢視網頁。
